# تنخ — پنجابی وِچ (selah-pnb)

ایتھے عبرانی پاک لکھت (تنخ) دا لہندی پنجابی وِچ، شاہ مُکھی لِپی وِچ، ترجمہ اے۔ ہر آیت اپنی اپنی فائل وِچ اے، تے ہر
پنجابی لفظ اوس عبرانی لفظ دے نال لکھیا اے جیہدا اوہ ترجمہ اے۔

> **ایہہ ترجمہ مشین نے بنایا اے، تے ایہہ پنجابی بولن والے دے کن دی اُڈیک وِچ اے۔** جتھے پنجابی ٹھیک نئیں لگدی،
> سوکھی نئیں لگدی، یا اوویں نئیں جیویں لوک سچی مُچی بولدے نیں — **اوہنوں ٹھیک کرنا اے۔** ہر لفظ دے نال عبرانی اے،
> تاں جو تُسیں آپ ویکھ سکو۔

**کجھ وی ٹھیک کرن توں پہلاں `CONTRIBUTING.md` پڑھو۔** کجھ گلاں جیہڑیاں بھُل لگدیاں نیں، جان بُجھ کے کیتیاں گئیاں نیں۔

## پہلاں عبرانی

ایہہ ترجمہ **تہانوں عبرانی تک لے جان لئی** اے — اوہدی تھاں لین لئی نئیں۔ اصل وِچ عبرانی پڑھی جاندی اے: اوہدے اکھر،
اوہدی آواز، اوہدے معنے۔ ایتھے دی پنجابی اِک باری اے، آخری بوہا نئیں۔ جدوں دوویں نئیں رلدیاں، عبرانی سچی اے۔

## ناں: `یاہوہ`

`יהוה` نوں **`یاہوہ`** لکھیا جاندا اے — عبرانی دے چار اکھر، ترتیب نال۔ **خداوند** نئیں، **رب** نئیں، **پرمیشر** نئیں،
**یہوواہ** نئیں؛ تے **خدا** اکلا ناں دی تھاں نئیں کھلوندا۔ **ایہہ ریتاں دے لفظ نیں — گواہاں دے تھمّے وِچ نیں، ساڈے
تھمّے وِچ نئیں۔** جدوں ناں ہٹا کے کوئی ہور لفظ رکھ دِتا جاندا اے، تاں پڑھن والا اوہ نئیں ویکھ سکدا جو عبرانی آکھدی اے۔

`אלהים` **`ایلوہیم`** اے؛ `אדני` (ربّ لئی) **`ادونای`**؛ `שדי` **`شدّای`**؛ `יהוה צבאות` **`یاہوہ تصواوت`**۔ پر
قوماں دے معبوداں لئی **`دیوتے`** لکھنا ٹھیک اے (خروج 32:8)، تے بندے مالک لئی **`سائیں`** یا **`میرا مالک`**۔

## `⟨את⟩`

`את` عبرانی وِچ مفعول دا نشان اے۔ **پنجابی وِچ ایہدے لئی کوئی لفظ نئیں**، ایس لئی ایہہ عبرانی ای رہندا اے، `⟨ ⟩` دے
اندر۔ `⟨ ⟩` دے اندر دے پنجابی لفظ عبرانی وِچ نئیں — پنجابی جملے نوں اوہناں دی لوڑ اے۔

## فائل کیویں دِسدی اے

پیدائش 1:1 (`genesis/1/1.json`):

```
شروع وِچ ایلوہیم نے ⟨את⟩ اسماناں نوں تے ⟨את⟩ دھرتی نوں بنایا۔
```

استثنا 6:4 (`deuteronomy/6/4.json`):

```
سُن، اے یِسرائیل: یاہوہ ساڈا ایلوہیم — یاہوہ اِک اے۔
```

ہر فائل وِچ اے: `translation` (پوری آیت پنجابی وِچ)، `tokens` (ہر عبرانی لفظ تے اوہدا پنجابی لفظ)، `notes` (مشین دے
اپنے نوٹ)، `model`، `timestamp`، تے `provenance` (مشین تے ہدایتاں جو ورتیاں گئیاں)۔
